# Simpletron en C

**Nombre:** Joaquin Blanca  
**Archivo:** `simpletron.c`

Simulador de la computadora Simpletron hecho en C para la tarea. 
Cumple con la memoria de 100 palabras, los registros pedidos, el centinela 9999 y las 12 instrucciones en SML. 
También detecta si hay errores (división entre 0, desbordamiento u operación inválida) y saca el vaciado de memoria al terminar.

## Compilación y ejecución
```bash
gcc simpletron.c -o simpletron.exe
./simpletron.exe
